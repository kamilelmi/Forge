# Forge: strength and conditioning

A personal training app that works offline on Android and Linux. It includes:

- **Your program:** a 3-day full-body plan (Day A, Day B, Day C) with top sets, back-off sets and supersets.
- **Guided workout tracker:**
  - Tells you what weight to lift each session, based on your last one.
  - Works out warm-up weights and the plates to load on each side of the bar.
  - Starts a rest timer by itself (supersets skip the rest between paired exercises), and keeps your workout if the page reloads.
  - Lets you swap exercises if the gym is busy.
  - Shows personal records when you finish.
- **Exercise guides:** illustrations of each exercise moving between its start and end position, plus a technique video, key coaching points, step-by-step instructions, the muscles worked, and your own history.
- **Norwegian 4×4 interval timer:** warm-up, 4 × 4 minutes hard with 3 minutes easy between, then a cool-down. It shows your heart-rate targets, beeps 3-2-1 and vibrates at every phase change, and keeps the screen on.
- **Zone 2 timer and log**, plus **VO2 max tracking** using the 12-minute run test or your watch's estimate.
- **History:** a strength progress chart (estimated 1-rep max) and every session you've logged.
- **Deload weeks, a weekly schedule you can change, backups, and light and dark themes.**

Your data stays on your device. Use **Settings → Export backup / Import and merge** to move it between devices.

## Put it online (GitHub Pages)

1. Create a new **public** repository on GitHub, e.g. `Forge`.
2. Click **"uploading an existing file"** and drag in **everything** in this folder, including the `img` folder. Then click **Commit changes**.
3. Go to **Settings → Pages**, set Branch to **main** and **/ (root)**, then click **Save**.
4. After a minute or two it's live at `https://YOUR-USERNAME.github.io/Forge/`.

## Install

- **Android:** open the link in Chrome, then **⋮ → Add to home screen → Install**.
- **Kubuntu:** open the link in Chrome or Chromium, then click the install icon in the address bar.

## Updating

Upload the changed files to the repository again. Installed copies update the next time you open them while online.
